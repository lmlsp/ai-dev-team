### 1.2 品类机会：合成（Merge）赛道

**全球市场（2025）：**
- Merge 品类全年收入约 **17 亿美元**，占休闲游戏份额 **17%**，同比增长 **95%**
- 二消合成（Match Merge 2）贡献了休闲游戏品类近 **60% 的同比收入增量**，是增长最强劲的子赛道
- 合成游戏在益智解谜大类中的收入占比从 14% → 20%（一年内提升 6 个百分点）

**微信小游戏生态内：**
- 益智消除品类是 **IAA 变现的第一大品类**，用户基数最大
- 合成类被微信官方定位为"女性向常青赛道"，适配泛用户、转化能力强
- 女性用户占比已达 **47%**，女性向付费涨幅接近男性向一倍

**结论：合成赛道处于黄金增长期，在微信生态内仍有品类红利。**

#### 市场空白

- 目前**没有一款以"中华美食烹饪"为主题的头部合成游戏**
- 现有合成产品偏重"装修"或"收集"，缺少"烹饪制作"的深度体验
- 美食题材天然适合社交分享（晒美食），但目前该潜力未被充分挖掘

### 1.6 选型理由

经过对 SLG、塔防、模拟经营、合成、消除五大方向的综合评估：

| 维度 | SLG | 塔防 | 模拟经营 | 合成消除 | 合成+经营 ✅ |
|------|-----|------|---------|---------|------------|
| 开发难度（1-2周/单人） | ❌ 极高 | ⚠️ 中高 | ⚠️ 中 | ✅ 低 | ✅ 低-中 |
| 社交裂变潜力 | ⚠️ 中 | ⚠️ 中 | ✅ 高 | ✅ 高 | ✅ 极高 |
| 广告变现成熟度 | ⚠️ 偏IAP | ⚠️ 偏IAP | ✅ 高 | ✅ 极高 | ✅ 极高 |
| 女性用户适配 | ❌ 低 | ❌ 低 | ✅ 高 | ✅ 极高 | ✅ 极高 |
| 市场竞争烈度 | ⚠️ 头部垄断 | ⚠️ 多强争霸 | ⚠️ 头部明显 | ⚠️ 红海 | ✅ 蓝海缝隙 |
| 玩法扩展性 | ⚠️ 中 | ✅ 高 | ✅ 高 | ❌ 低 | ✅ 极高 |

**最终选择：二合消除（Merge-2）+ 餐厅经营**

- 开发可行：核心 Merge-2 逻辑成熟，1-2 周单人可完成 MVP
- 商业可行：休闲消除是 IAA 第一大品类，广告变现效率最高
- 用户匹配：美食主题天然吸引女性用户（47% 且增长最快）
- 社交裂变：烹饪成果天然适合分享，社交数据碾压纯单机
- 差异化：中华美食 + 烹饪深度体验，市面无直接竞品

## 4. 核心玩法描述

### 4.1 游戏概述

《合合小厨神》是一款以**中华美食烹饪**为主题的**二合消除（Merge-2）+ 餐厅经营**休闲小游戏。玩家通过合成食材、制作菜品、服务顾客来经营自己的餐厅，从街边小摊逐步升级为米其林星级餐厅。

### 4.2 核心循环

```
     ┌──────────────────────────────────────┐
     │                                      │
     ▼                                      │
┌─────────┐    ┌─────────┐    ┌─────────┐   │
│ 生成食材 │───▶│ 二合合成 │───▶│ 制作菜品 │   │
│ (Board) │    │ (Merge) │    │ (Cook)  │   │
└─────────┘    └─────────┘    └────┬────┘   │
                                   │        │
                                   ▼        │
                              ┌─────────┐   │
                              │ 服务顾客 │   │
                              │ (Serve) │   │
                              └────┬────┘   │
                                   │        │
                                   ▼        │
            ┌────────────────────────────────┘
            │
            ▼
      ┌─────────┐     ┌──────────┐     ┌─────────┐
      │ 赚取金币 │────▶│ 升级餐厅  │────▶│ 解锁新菜 │
      │ (Earn)  │     │(Upgrade) │     │(Unlock) │
      └─────────┘     └──────────┘     └─────────┘
```

### 4.3 合成系统（Merge Board）

**棋盘规格：**
- 初始：5×6（30 格）
- 可扩展至 6×7（42 格），通过餐厅升级解锁

**生成规则：**
- 每 30 秒自动生成 1 个随机初级食材（Lv.0）
- 棋盘格位上限 30 格，满格时停止生成
- 看激励视频可立即生成 3 个食材（IAA 核心点位）

**合成规则：**
- 拖拽 2 个**相同**食材/菜品到同一格 → 合成 1 个**升级版**
- 合成公式为线性链（非分支）：Lv.0 + Lv.0 → Lv.1 → Lv.1 + Lv.1 → Lv.2 → ...
- 部分高级合成需要跨品类（如"番茄炒蛋" = 番茄酱 Lv.2 + 鸡蛋液 Lv.3）
- 合成时播放粒子特效 + 音效反馈

**合成链示例（番茄炒蛋线）：**

```
番茄 Lv.0 ──+──→ 番茄块 Lv.1 ──+──→ 番茄酱 Lv.2
                                          │
                                          +──→ 番茄炒蛋 (菜品) ──→ 番茄蛋套餐
                                          │
鸡蛋 Lv.0 ──+──→ 蛋液 Lv.1 ──+──→ 蛋皮 Lv.2 ──+──→ 炒蛋 Lv.3
```

### 4.4 接单系统（Order Board）

**顾客生成：**
- 顶部滚动显示 3 个顾客队列
- 每位顾客携带 1 个菜品需求，附带等待计时器（60-120 秒）
- 顾客头像随机生成，附带趣味昵称

**接单流程：**
1. 顾客出现 → 显示所需菜品名称 + 等待倒计时
2. 玩家从 Merge Board 拖拽对应已完成菜品 → 自动上菜
3. 上菜成功 → 获得金币 + 好评度（⭐）
4. 等待超时 → 顾客生气离开 → 扣除好评度

**好评度系统：**
- 初始 3.0 ⭐，上限 5.0 ⭐
- 好评度影响：顾客数量、高级菜品订单概率、小费概率
- 好评度 < 2.0 → 触发"餐厅危机"事件（限时补救任务）

### 4.5 餐厅经营系统

**餐厅等级：**

| 等级 | 名称 | 解锁条件 | 解锁内容 |
|------|------|---------|---------|
| Lv.1 | 街边小摊 | 初始 | 基础菜系（8 种家常菜），棋盘 5×6 |
| Lv.2 | 小饭馆 | 500 金币 + 好评 3.5⭐ | 川菜菜系（8 种），装饰位 +2 |
| Lv.3 | 人气餐厅 | 2000 金币 + 好评 4.0⭐ | 粤菜菜系（8 种），棋盘 6×7 |
| Lv.4 | 知名酒楼 | 5000 金币 + 好评 4.5⭐ | 创意融合菜（6 种），VIP 顾客 |
| Lv.5 | 米其林星级 | 10000 金币 + 好评 5.0⭐ | 隐藏菜谱（4 种），终极装饰 |

**总计 34 种可解锁菜品，覆盖 4 大中华菜系。**

### 4.6 能量系统

| 参数 | 数值 |
|------|------|
| 能量上限 | 100 点 |
| 合成消耗 | 1 点/次合成 |
| 自动恢复 | 1 点/3 分钟（满需 5 小时） |
| 看广告恢复 | 30 点/次（每日上限 10 次） |
| 好友赠送 | 10 点/次（每日上限 5 次） |

### 4.7 社交系统

**好友餐厅拜访：**
- 通过微信好友关系链，拜访好友餐厅
- 拜访可获得"灵感值"（用于临时加速食材生成）
- 每日拜访上限 10 次
- 可给好友"点赞"（累计赞数影响餐厅展示排序）

**排行榜：**
- 周榜：每周好评度排名
- 总榜：餐厅等级排名
- 仅展示微信好友 + 匿名随机玩家

**分享节点（自然分享，严禁诱导）：**
- 合成出稀有菜品时 → 分享菜品图鉴
- 餐厅升级时 → 分享餐厅名片
- 每周排行榜结算 → 分享排名

### 5.2 页面功能详述

#### P1 加载页 `/loading`

- **功能**：资源预加载（图片、音频、配置表）、版本号比对、静默微信登录
- **UI 元素**：背景图 + 进度条 + Tips 轮播（如"番茄炒蛋是国民第一家常菜"）

- **弱网策略**：本地有缓存 → 先进入游戏（离线模式），后台异步同步

## 7. 异常场景

### 7.1 网络异常

| 场景 | 用户表现 | 系统行为 | 恢复策略 |
|------|---------|---------|---------|
| **弱网（2G/3G）** | 操作响应延迟 | 合并、上菜等核心操作本地执行，异步同步；非关键请求（排行榜刷新）静默失败 | 网络恢复后批量同步，冲突以服务端为准 |
| **断网** | 无法加载新资源 | 本地缓存数据正常游戏；顶部显示"网络断开"轻提示（非阻断式） | 网络恢复后自动重连，数据增量同步 |
| **请求超时** | 操作无响应 | 自动重试 3 次（间隔 1s/3s/5s）；3 次失败后本地执行，标记脏数据 | 下次成功请求时一并同步 |
| **广告加载失败** | 点击看广告无反应 | Toast "广告加载中，请稍后再试"；不扣能量/道具 | 3 秒后可重新点击 |
| **排行榜加载失败** | 排行榜空白 | 展示本地缓存的上次排行数据 + "刷新失败"提示 | 下拉手动刷新 |

### 7.2 数据异常

| 场景 | 处理策略 |
|------|---------|
| **本地数据损坏** | 检测到数据格式异常 → 清除本地缓存 → 从云端拉取最新存档 → 如云端也无则初始化新档 |
| **云端数据不一致** | 以服务端数据为准，客户端静默覆盖（用户无感知） |
| **时间篡改**（修改系统时间加速能量） | 服务端记录时间戳，能量恢复以服务端时间为准，拒绝客户端上报的时间差 |
| **金币/道具异常增量** | 关键资源（金币、钻石、道具）的增减必须通过服务端校验，客户端仅做乐观更新 |
| **并发操作冲突** | 短时间内的重复请求（如连点合成），服务端取第一次成功结果，后续返回幂等结果 |

### 7.3 加载异常

| 场景 | 处理策略 |
|------|---------|
| **首次加载超时（>10s）** | 显示重试按钮 + "网络较慢，请检查网络后重试" |
| **首次加载超时（>30s）** | 提供"跳过加载（离线模式）"选项，本地兜底资源保证基础可玩 |
| **资源更新失败** | 保留上一版本资源继续可用；后台静默重试更新，下次启动生效 |
| **分包加载失败** | 非核心页面（排行榜、图鉴详情图片）使用占位图 + 重试按钮 |
| **微信登录失败** | 提供"游客模式"进入游戏（限制社交功能），同时提供手动授权重试入口 |

### 7.4 交互异常

| 场景 | 处理策略 |
|------|---------|
| **误操作（误拖拽）** | 合成前 0.5s 内可撤回（撤销动画）；已合成的不可逆 |
| **棋盘满格** | 提示"格子满了，卖出或合成腾出空间吧"；高亮可卖出的低价值食材 |
| **能量不足** | 合成按钮灰显 + "能量不足"提示 + "看广告获取 30 能量"入口 |
| **来电/切后台** | 自动暂停能量计时；回到前台时展示"欢迎回来" + 离线期间收益摘要（上限 2 小时） |
| **手机低电量** | 不做特殊处理（系统层面处理） |
| **横竖屏切换** | 锁定竖屏，不支持横屏 |

### 7.5 边界情况

| 场景 | 处理策略 |
|------|---------|
| **新手引导中被中断**（来电/切后台） | 回到前台时从当前引导步骤继续，引导状态持久化 |
| **同时收到多个顾客同一菜品订单** | 允许，多个顾客可点相同菜品；共享同一菜品库存 |
| **合成链末端菜品不可再合成** | 成品菜显示"可上菜"标记，拖拽到订单区；不可再与其他食材合成 |
| **好友列表为空** | 排行榜展示匿名随机玩家 + "邀请好友一起玩"入口 |
| **首次进入无好友** | 展示系统推荐的好友（活跃玩家），降低冷启动社交压力 |
| **顾客订单所需菜品尚未解锁** | V1.0 不会出现：订单池仅从已解锁菜品中抽取 |

## 9. 国际化考虑

### 9.1 V1.0 策略

**仅支持简体中文（zh-CN），但架构预留国际化能力。**

### 9.2 国际化架构设计

- 所有用户可见文案使用 `i18n.t(key)` 调用，不硬编码
- 文案存储在 `locales/zh-CN.json` 中，后续新增语言只需新增 JSON 文件
- 数字格式化使用 `Intl.NumberFormat`（货币、日期等）
- 菜品名称保留中文拼音 + 英文解释（如 "番茄炒蛋 (Tomato Egg Stir-fry)"）

### 9.3 未来国际化优先级

| 优先级 | 语言 | 理由 |
|--------|------|------|
| P0 | 简体中文 (zh-CN) | 首发市场 |
| P1 | 繁体中文 (zh-TW) | 港澳台市场，中华美食文化共鸣 |
| P2 | 英语 (en-US) | 海外华人 + 对中国美食感兴趣的外国人 |
| P3 | 日语 (ja-JP)、韩语 (ko-KR) | 东亚文化圈，对中餐接受度高 |

### 9.4 文化适配注意

- 菜品选择：优先中华家常菜（番茄炒蛋、宫保鸡丁等海外认知度高的菜）
- 画面风格：Q 版卡通，跨国界通用
- 数字格式：千分位分隔符（1,000）
- 货币符号：V1.0 使用金币（虚拟货币），未来出海时考虑本地化

### 10.2 核心风险详解

#### 风险 1：微信"诱导分享"红线

这是最大风险。微信安全中心 2026 年 1 月将"过度营销与诱导分享"列为三大重点打击对象。

**我们的红线自查：**
- ✅ 不做"分享后才能继续游戏"
- ✅ 不做"分享才能获得奖励"
- ✅ 不做"集赞/助力/砍价"类运营
- ✅ 分享入口为自然触发（完成里程碑时），可关闭
- ✅ 分享奖励为软性激励（如"分享后好友来访可得灵感值"），非等价交换

#### 风险 2：合成品类竞争加剧

合成品类全球同比增长 95%，必然吸引更多入局者。

**我们的护城河：**
- 中华美食文化题材（非装修、非农场，差异化足够强）
- 烹饪过程的"深度"——不是简单合并，而是有合成链的探索乐趣
- 社交差异化——好友餐厅拜访、排行榜，利用微信关系链

## 11. 商业化策略

### 11.1 变现模式选择

**V1.0 纯 IAA（广告变现），V1.1 引入轻 IAP。**

**理由：**
- 休闲消除品类是 IAA 第一大品类，变现效率已验证
- 目标用户（女性 25-45 岁）对广告接受度高，付费意愿成长中
- IAA MAU 4 亿 > IAP MAU 3 亿，用户覆盖面更广
- 平台政策：IAP 新游 5000 万流水内不分成，但我们的用户基数战略更适合 IAA

### 11.2 广告点位设计

| 序号 | 点位 | 类型 | 触发方式 | 预估频次（日/人） | 优先级 |
|------|------|------|---------|-----------------|--------|
| A1 | 能量恢复 | 激励视频 | 玩家主动点击"看广告获取 30 能量" | 3-5 次 | P0 |
| A2 | 食材加速 | 激励视频 | 棋盘满时，点"加速生成 3 食材" | 2-3 次 | P0 |
| A3 | 金币翻倍 | 激励视频 | 上菜后弹出"看广告金币翻倍"（可选） | 2-4 次 | P0 |
| A4 | 延长等待 | 激励视频 | 顾客即将超时，"看广告延长时间" | 1-2 次 | P1 |
| A5 | 底部 Banner | Banner | 游戏主界面底部常驻 | 持续展示 | P1 |
| A6 | 自然插屏 | 插屏 | 餐厅升级完成后（非打断式，场景过渡） | 1-2 次 | P2 |

**设计原则：**
- 激励视频为唯一"用户主动发起"的广告（不被打断，体验可控）
- Banner 不遮挡核心操作区
- 插屏仅在场景过渡时展示（升级成功/关卡切换），拒绝"突然弹出"
- 新用户前 5 分钟不展示任何广告（保护体验，提高留存）

### 11.3 激励视频点位详设

#### A1：能量恢复（核心变现点位）

- 触发：能量不足时，点击棋盘旁的"⚡+"按钮
- 广告时长：15-30 秒激励视频
- 奖励：恢复 30 点能量
- 每日上限：10 次
- 预期贡献：占总广告收入的 40%

#### A2：食材加速

- 触发：棋盘满格时，自动弹出轻提示"格子满了？看广告获得 3 个新食材"
- 广告时长：15-30 秒激励视频
- 奖励：立即生成 3 个随机 Lv.1 食材（非 Lv.0，提升吸引力）
- 每日上限：8 次
- 预期贡献：占总广告收入的 25%

#### A3：金币翻倍

- 触发：完成上菜后，结算弹窗中展示"看广告翻倍（+X 金币）"按钮
- 广告时长：15-30 秒激励视频
- 奖励：本次获得金币 ×2
- 每日上限：无（但受菜品产出速度自然限制）
- 预期贡献：占总广告收入的 20%

### 11.4 广告平台策略

| 优先级 | 平台 | 填充场景 |
|--------|------|---------|
| 1 | 优量汇（腾讯广告） | 微信生态内最优填充率，主力平台 |
| 2 | 穿山甲（字节跳动） | 补充填充，eCPM 有时高于优量汇 |
| 3 | Google AdMob | 仅海外用户（V1.0 无海外，预留） |

使用瀑布流（Waterfall）模式：优量汇优先 → 优量汇填充失败 → 穿山甲 → 无填充则降级为不展示广告。
