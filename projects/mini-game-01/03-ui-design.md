## 1. 设计定位

### 1.1 整体风格：三个关键词

| 关键词 | 说明 |
|--------|------|
| **温暖** | 以暖色调为主，传递厨房的温度和家的感觉，适配女性用户偏好 |
| **Q 萌** | 圆角、圆润、食材拟人化，降低认知门槛，覆盖 40+ 岁用户 |
| **轻快** | 高饱和度点缀色、弹性动画、快速反馈，制造"爽感" |

### 1.2 情绪板

```
视觉感受：
┌────────────────────────────────────────────────────┐
│  温暖厨房 · 治愈美食 · 快乐收集                      │
│                                                    │
│  想象一个阳光洒进厨房的午后：                         │
│  · 木质台面上摆放着新鲜的番茄、鸡蛋                   │
│  · 锅里咕嘟咕嘟冒着热气                             │
│  · 桌边的小黑板上写着今日菜单                         │
│  · 客人推门而入，铃铛叮当作响                         │
│                                                    │
│  视觉关键词：木纹 · 陶瓷白 · 暖黄光 · 新鲜食材色      │
└────────────────────────────────────────────────────┘
```

### 1.3 设计语言统一说明

- **圆角系统**：所有组件遵循 4/8/12/16/24px 五级圆角体系
- **阴影系统**：轻阴影（卡片悬浮）+ 柔阴影（弹窗蒙层），不出现硬阴影
- **间距系统**：基准 4px，常用 8/12/16/20/24/32px
- **图标风格**：线性图标（2px 描边）+ Emoji 食材，混搭但不违和
- **Z-Index 分层**：
  - 0-9：页面内容
  - 10-19：悬浮元素（FAB、顾客卡片）
  - 20-29：弹窗/蒙层
  - 30-39：新手引导蒙层
  - 40-49：Toast/提示

### 2.2 颜色使用规则

- **主色 #FF6B35** 不用于大面积背景，仅用于交互元素和强调
- **暖白 #FFF8F2** 为页面主背景，营造温暖感而非纯白冷感
- **文字层级**：主要文字必须用 #2C1810（非纯黑 #000），次要用 #8B6F5F
- 所有颜色在棋盘区域需保证 **对比度 ≥ 4.5:1**（食材可辨认）

### 2.3 暗色模式

V1.0 仅支持浅色模式。但颜色变量命名预留 `--color-bg-primary` 等形式，方便后续扩展。

font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",

## 4. 组件规范

### 4.1 棋盘格子（Merge Cell）

格子是棋盘的基本单位，尺寸见 Canvas 章节。此处定义视觉状态：

| 状态 | 视觉呈现 | 参数 |
|------|---------|------|
| **空格子** | 背景色 `#F5E6D8`，内凹阴影，圆角 8px | `box-shadow: inset 0 2px 4px rgba(0,0,0,0.06)` |
| **有食材 Lv.0** | 格子正常，食材居中 60% 格宽 | 无特殊效果 |
| **有食材 Lv.1** | 食材 65% 格宽，微弱发光 | `box-shadow: 0 0 6px rgba(255,107,53,0.2)` |
| **有食材 Lv.2** | 食材 70% 格宽，边框渐变暖橙色 | 边框 1.5px `#FFB347` |
| **有食材 Lv.3（菜品）** | 食材 75% 格宽，金色虚线边框 + 微光呼吸 | 边框 2px `#FFB347` dashed，呼吸动画 |
| **有食材 Lv.4（稀有）** | 食材 80% 格宽，彩虹边框旋转 | 边框 2px 渐变旋转动画 |
| **可合成高亮** | 两个相同食材相邻时，二者同时亮起 | 背景 `#FFF0E8`，边框 `#FF6B35` |
| **被拖拽中（源格）** | 食材消失，格子轻微凹入 | 内阴影加深 + 原位置留虚线框 |
| **目标格高亮** | 拖拽经过的有效目标格亮起 | 背景 `#FFF0E8` + 虚线边框 `#FF6B35` |
| **满格闪烁** | 棋盘满时，空格边框微微闪烁 | 所有空格边框闪烁 `#FF5252` 0.8s |

### 4.2 食材图标

#### 4.2.1 食材等级视觉层级

| 等级 | 视觉特征 | 实现方式 |
|------|---------|---------|
| **Lv.0 初级食材** | 纯 Emoji，无装饰 | 如 `🍅` 36×36px |
| **Lv.1 加工食材** | Emoji + 白色圆底 + 1px 浅边框 | 圆底直径 44px，Emoji 32×32px |
| **Lv.2 半成品** | Emoji + 暖橙色圆底 + 细阴影 | 圆底直径 50px，Emoji 36×36px |
| **Lv.3 成品菜** | Emoji + 金色渐变圆底 + 发光 | 圆底直径 56px，Emoji 40×40px |
| **Lv.4 稀有菜** | Emoji + 彩虹渐变圆底 + 旋转光晕 | 圆底直径 62px，Emoji 44×44px |

#### 4.2.2 食材实现方案

采用 **Emoji 主 + 色块底衬** 方案：
- 食材本体：Emoji（系统原生渲染，无需额外资源）
- 底衬颜色：对应食材品类颜色（蔬菜绿、肉类红、海鲜蓝、调料黄）
- 等级角标：右下角小圆点，标注 Lv 数字

```
食材绘制层级（从底到顶）：
┌─────────────────┐
│ 1. 圆角方形底色   │  ← 白色/暖橙色/金色（按等级）
│ 2. Emoji 居中     │  ← 食材本体
│ 3. 等级角标       │  ← 右下角 16px 小圆 + Lv 数字
│ 4. 光效叠加       │  ← Lv.3+ 才有
└─────────────────┘
```

#### 4.2.3 品类底色

| 品类 | 底色 | 说明 |
|------|------|------|
| 蔬菜 | `#E8F5E9` | 淡绿底 |
| 肉类 | `#FFEBEE` | 淡红底 |
| 海鲜 | `#E3F2FD` | 淡蓝底 |
| 调料 | `#FFF3E0` | 淡橙底 |
| 成品菜 | `#FFFDE7` | 淡金底 |
| 稀有菜 | `#F3E5F5` | 淡紫底 + 渐变边框 |

### 4.3 顾客卡片

```
┌──────────────────────────┐
│ ┌──┐                     │
│ │头像│  顾客昵称           │  ← 48×48px 圆形头像 + 昵称
│ └──┘                     │
│                          │
│    🍳  番茄炒蛋           │  ← 菜品 Emoji + 名称
│                          │
│  ⏱ ────────────── ●     │  ← 倒计时圆环进度条
│        45s               │  ← 剩余时间文字
└──────────────────────────┘
```

| 属性 | 参数 |
|------|------|
| 卡片尺寸 | 100×130px |
| 卡片圆角 | 12px |
| 卡片背景 | `#FFFFFF` |
| 卡片阴影 | `0 2px 8px rgba(45,24,10,0.08)` |
| 头像占位 | 48px 圆形，默认灰色底 + 👤 Emoji |
| 菜品图标 | Emoji 32×32px，居中 |
| 倒计时圆环 | 外径 36px，线宽 3px |
| 倒计时正常色 | `#4CAF50`（> 20s） |
| 倒计时警告色 | `#FFB347`（10-20s） |
| 倒计时超时色 | `#FF5252` 闪烁（< 10s） |
| 圆环底色 | `#EDE4DA` |

**倒计时圆环实现：**
- 使用 Canvas 绘制弧形进度条（`ctx.arc()`）
- 剩余时间 / 总时间 = 弧长比例
- 卡片整体在超时前 10s 开始微微抖动（`translateX` ±2px，周期 0.3s）

### 4.4 按钮

#### 4.4.1 按钮规格

| 类型 | 尺寸 | 圆角 | 背景色 | 文字色 | 使用场景 |
|------|------|------|--------|--------|---------|
| **主按钮** | 280×48px | 24px（全圆） | `#FF6B35` | `#FFFFFF` | 确认升级、开始游戏 |
| **主按钮-按下** | 同上 | 同上 | `#E55A2B` | `#FFFFFF` | 按下反馈 |
| **次按钮** | 280×48px | 24px | `#FFFFFF` + 1.5px `#FF6B35` | `#FF6B35` | 取消、稍后再说 |
| **次按钮-按下** | 同上 | 同上 | `#FFF0E8` | `#E55A2B` | 按下反馈 |
| **广告按钮** | 160×40px | 20px | `#FFB347` + ▶️ 图标 | `#FFFFFF` | 看广告加速/恢复 |
| **广告按钮-按下** | 同上 | 同上 | `#E69520` | `#FFFFFF` | 按下反馈 |
| **小按钮** | 80×32px | 16px | `#FF6B35` | `#FFFFFF` | 卖出、使用道具 |
| **图标按钮** | 44×44px | 22px | 透明 | `#8B6F5F` | 返回、关闭、设置 |

#### 4.4.2 按钮通用规范

- 最小点击区域：44×44px（微信设计规范）
- 按钮间距：≥ 12px（防止误触）
- 按下态：背景变暗 10% + `scale(0.96)` 0.1s
- 禁用态：背景 `#EDE4DA`，文字 `#C4B5AC`，不响应点击
- 加载态：文字替换为 20px 旋转圆环（`#FFFFFF`）

### 4.9 顶部状态栏

```
基准宽度 390px（iPhone 14）
┌──────────────────────────────────┐
│ ← [头像]  Lv.3   🪙1,234  ⚡75  │  ← 高度 44px
│            人气餐厅               │    padding 左右 16px
└──────────────────────────────────┘
```

| 属性 | 参数 |

## 7. 动效设计

### 7.1 动效总表

| 动效名称 | 触发场景 | 时长 | 缓动函数 | 表现 |
|---------|---------|------|---------|------|
| **合成成功** | 两个食材合成 | 600ms | `ease-out` + `ease-out-back` | 粒子爆发 400ms + 格子回弹 200ms |
| **上菜飞行** | 拖菜品到顾客 | 400ms | `ease-out` | 贝塞尔曲线飞行动画 |
| **金币 +N** | 上菜/卖出成功 | 1000ms | `ease-out` | +N 文字上飘 40px 后淡出 |
| **顾客超时离开** | 等待超时 | 500ms | `ease-in` | 失望表情 + scale(0.8) + opacity(0) |
| **餐厅升级** | 点击升级确认 | 2000ms | 分阶段 | 全屏烟花 1.5s + 卡片弹入 0.5s |
| **食材生成** | 新食材出现 | 300ms | `ease-out-back` | 底部冒出 + 弹性回弹 |
| **页面切换-推入** | navigateTo | 300ms | `ease-out` | 右→左滑入 |
| **页面切换-返回** | navigateBack | 300ms | `ease-out` | 左→右滑出 |
| **弹窗弹入** | 弹窗出现 | 300ms | `ease-out-back` | scale(0.8)→(1.0) + opacity |
| **弹窗淡出** | 弹窗关闭 | 200ms | `ease-in` | scale(1.0)→(0.9) + opacity |
| **拖拽拾起** | 手指触碰食材 | 100ms | `ease-out` | scale(1.0)→(1.1) + shadow |
| **拖拽释放** | 松手未合成 | 200ms | `ease-out-back` | 弹回原位 |
| **能量恢复** | 能量 +1 时 | 300ms | `linear` | 进度条平滑增长 |
| **点赞爱心** | 点击好友点赞 | 500ms | `ease-out-back` | 爱心 scale(1.0)→(1.5)→(1.0) |
| **提示闪烁** | 棋盘满格 | 800ms 循环 | `ease-in-out` | 空格边框闪烁 |
| **能量不足闪烁** | 能量<20 | 600ms 循环 | 线性 | opacity 1.0↔0.5 |

### 7.2 缓动函数定义

| 名称 | CSS cubic-bezier | 用途 |
|------|-----------------|------|
| `ease-out` | `(0.25, 0.46, 0.45, 0.94)` | 入场动画（减速结束） |
| `ease-in` | `(0.55, 0.06, 0.68, 0.19)` | 退场动画（加速离开） |
| `ease-in-out` | `(0.42, 0, 0.58, 1)` | 循环动画 |
| `ease-out-back` | `(0.34, 1.56, 0.64, 1)` | 弹性回弹效果 |
| `linear` | `(0, 0, 1, 1)` | 进度条、循环 |

### 7.3 动画性能要求

- Canvas 内所有动画使用 `requestAnimationFrame` 驱动，避免 `setInterval`
- 粒子数量控制在 50 以内，超出时降低帧率至 30fps 而非丢帧
- 低端机（< Android 8 / < iPhone 8）：自动降级为简化粒子（数量减半，仅 ⭐，去掉火花光点）
- 禁止使用 `setData` 触发高频动画（Canvas 直接绘制）

### 8.2 关键交互流程

#### 拖拽合成流程

```
touchstart（移动 < 8px，不触发）
    │
    ▼
touchmove（移动 ≥ 8px）→ 食材跟随手指，源格留虚线框
    │
    │  途经有效目标格 → 目标格高亮（橙色虚线边框）
    │  途经无效格 → 无反馈
    │  移至订单区 → 订单区高亮（如果菜品可上菜）
    │
    ▼
touchend
    │
    ├── 落在同类型同等级食材格上 → 合成成功
    │       ├── 0-200ms：食材重合动画（目标格食材消失，新食材出现）
    │       ├── 200-400ms：粒子爆开
    │       ├── 400-600ms：新食材弹性回弹
    │       └── 不可逆（已扣除能量，服务端已记录）
    │
    ├── 落在有效菜品格 + 在订单区释放 → 上菜成功
    │       ├── 0-400ms：菜品飞行到顾客卡片
    │       ├── 400-600ms：金币+N 飘字
    │       └── 不可逆
    │
    └── 落在其他位置 → 食材弹回原位（200ms ease-out-back）
```

#### 误操作防护

| 场景 | 防护策略 |
|------|---------|
| 误拖拽（< 8px 移动） | 不触发拖拽，视为 Tap |
| 合成后立即后悔 | 不可逆（200ms 后已同步服务端） |
| 连点合成 | 合成期间 200ms 内忽略同一格的新 touchstart |
| 棋盘满时拖拽 | 限制拖拽食材仅在相邻空格外释放（不能放回原处以外） |

### 9.2 rpx 换算表

| 设计 px (390 基准) | rpx | 说明 |
|-------------------|-----|------|

| 16px | 32rpx | 页面边距 |

### 9.3 Android 异形屏安全区

```css
/* 顶部安全区 */
.top-bar {
  padding-top: calc(var(--status-bar-height) + 0px);
  /* var(--status-bar-height) = wx.getSystemInfoSync().statusBarHeight */
}

/* 底部安全区 */
.bottom-bar {
  padding-bottom: env(safe-area-inset-bottom);
}
```

| 区域 | 参数 | 说明 |
|------|------|------|
| 顶部安全区 | `statusBarHeight`（系统 API 获取） | 通常 20-48px |
| 底部安全区 | `safeAreaInsets.bottom` | iPhone X+ 为 34px，Android 异形屏 0-24px |
| 顶部状态栏背景 | 延伸至 statusBar 区域，半透明 | 沉浸式设计 |
| 底部栏 padding | 底部栏 padding-bottom = safeAreaBottom | 不被导航条遮挡 |

### 9.4 Canvas 棋盘缩放策略

```javascript
function calculateBoardScale() {
  const sysInfo = wx.getSystemInfoSync();
  const screenWidth = sysInfo.windowWidth;
  const screenHeight = sysInfo.windowHeight;

  // 预留空间
  const topBarHeight = 44 + sysInfo.statusBarHeight;
  const orderQueueHeight = 100;
  const bottomBarHeight = 56 + (sysInfo.safeAreaInsets?.bottom || 0);
  const padding = 32; // 上下各 16px

  const availableHeight = screenHeight - topBarHeight - orderQueueHeight
    - bottomBarHeight - padding;
  const availableWidth = screenWidth - 40; // 左右各 20px

  const boardWidth = 324;  // 5×6 设计宽度
  const boardHeight = 386; // 5×6 设计高度

  const scaleX = availableWidth / boardWidth;
  const scaleY = availableHeight / boardHeight;
  const scale = Math.min(scaleX, scaleY, 1.0); // 最大 1.0，不放大会模糊

  return scale;
}
```

### 11.3 Emoji 跨平台一致性

| 平台 | Emoji 渲染 | 差异说明 |
|------|-----------|---------|
| iOS 16+ | 原生 Emoji，色彩饱和，细节丰富 | 基准效果 |
| Android 12+ | 原生 Emoji，色彩偏淡，形状略不同 | 🥩🫑 等差异较大 |
| Android 9-11 | 旧版 Emoji，部分 Emoji 不支持（显示☐） | 需降级为文字 |

**降级方案（Android 9-11）：**
- 对不支持的 Emoji（如 🫑🫘🥡），Canvas 绘制时检测渲染宽度 = 0 则用文字缩写代替
- 如 🫑 → "椒"，🫘 → "豆"
