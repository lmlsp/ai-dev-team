# AI 小程序研发团队

一个模拟完整软件研发团队的 AI 协作系统。从需求分析到部署上线，7 个角色通过文档流转协作，形成完整研发闭环。

## 角色

| 角色 | 职责 |
|------|------|
| 产品经理 | PRD、用户流程、页面规划、权限设计、边界条件 |
| 系统架构师 | 技术选型、API设计、数据库设计、安全/性能方案 |
| UI/UX 设计师 | 页面布局、交互设计、动效、小程序交互规范 |
| 开发工程师 | Vue3/uni-app + Spring Boot 完整代码实现 |
| Code Reviewer | 安全/性能/工程规范审查，问题必须修复 |
| QA 工程师 | 功能/边界/异常/并发/压力测试 |
| DevOps | Docker、CI/CD、Nginx、监控、回滚 |

## 工作流程

```
需求 → Product → Architect → UI Designer(可选) → Developer → Reviewer → QA → DevOps → 上线
```

每个阶段输出结构化文档，下一阶段以文档为输入，禁止共享全部上下文。

## 技术栈

- **前端**: Vue3 + uni-app / Taro
- **后端**: Spring Boot
- **数据库**: MySQL + Redis
- **部署**: Docker + Nginx

## 目录结构

```
ai-dev-team/
├── TEAM.md           # 团队角色定义与协作规范
└── projects/         # 各项目方案与代码（按需求组织）
```

## 使用方式

向 AI 提出小程序功能需求，系统自动按角色串行推进，每阶段输出文档等待确认后继续。
